# React Showcase

A modern frontend application built using React, TypeScript, and Vite. The project follows a scalable component-based architecture with TanStack Router for routing and Tailwind CSS for styling.

---

## 🚀 Technologies Used

- React.js
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS
- Node.js
- npm
- ESLint
- Prettier
- Git

---

## 📁 Project Structure

```
src/
│
├── assets/          # Images, Icons, Fonts
├── components/      # Reusable UI Components
├── hooks/           # Custom React Hooks
├── lib/             # Utility Functions
├── routes/          # Application Routes
│
public/              # Static Files
```

---

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate into the project

```bash
cd react-showcase
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://10.132.187.192:8080/
```
